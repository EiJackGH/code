## 2025-07-07 - Accessible Game Instructions
**Learning:** When adding dynamic status updates (like scores) to web UI elements like `src/views/mario-game.njk`, including `aria-live="polite"` and `aria-atomic="true"` maintains screen reader accessibility. However, static instructional text must not be placed inside an `aria-live` region, as it forces screen readers to unnecessarily repeat the static text every time the dynamic content updates.
**Action:** Extract static text into a separate sibling element when building interactive HTML5 widgets or games with custom keyboard event bindings, and always provide explicit, visible instructional text so users know the required inputs.
